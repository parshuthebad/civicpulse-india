# CivicPulse — National Deepfake & Fact-Verification Portal (Government of India Initiative)

**Track 1: Civic Pulse, Digital Governance & Public Information**

An Apple-inspired, official Government of India web portal for real-time Fact-Verification, Deepfake Image/Video Forensics, Audio Voice-Clone Auditing, Real-Time Camera Person & Object Detection, Harmful/Deepfake Content Safety Alerts, and Integrated Cyber Complaint Filing.

## Quick Start in VS Code (Windows PowerShell)
```powershell
cd civicpulse-audit
.\run.ps1
```
Then open **http://127.0.0.1:8000** in Chrome or Edge.
